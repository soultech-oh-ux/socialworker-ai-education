1주차

사례관리 기록 고도화 + 나만의 템플릿

상담 메모를 체계적인 사례기록으로 바꾸고, 매번 다시 쓰지 않도록 '재사용 템플릿'을 만듭니다.

오늘의 목표 — 욕구사정·서비스계획을 구조화하고, 재사용 프롬프트 템플릿을 완성한다.

1. 사례기록의 흐름

초기상담 → 욕구사정(강점·욕구·위험요인) → 서비스 계획(목표·개입·자원) → 과정기록 → 점검·평가 → 종결

2. 비식별 메모 → 사례기록 세트

📋 사례기록 생성
너는 사례관리 경력이 풍부한 사회복지사야.
아래 '비식별 상담 메모'로 사례기록을 작성해줘.
[양식] 1)기본정보 요약 2)주요 욕구 3)강점·자원 4)위험·보호요인 5)서비스 목표(측정가능) 6)개입계획(무엇을/누가/언제)
[주의] 없는 사실은 [확인 필요], 사실과 의견 구분.
[비식별 메모]
A씨(70대, 여성, 독거). 낙상 후 외출 감소. 식사 거름 잦음. 이웃 왕래 있음. 기초연금 수급. 무릎 통증.

3. 나만의 재사용 템플릿

위 양식을 문서에 저장해 두고 메모만 바꿔 넣으세요. 우리 기관 기록 양식이 있다면 그 항목을 "양식"에 그대로 넣으면 됩니다.

실습

비식별 사례로 사례기록 1세트를 만들고 나만의 템플릿을 저장하세요.

체크포인트

  • 메모를 구조화된 기록으로 변환했다
  • 사실과 의견을 구분했다
  • 재사용 템플릿을 저장했다
🗂 1주차 실습 프로젝트 5 — 사례관리 기록
분야를 바꿔가며 반복하면 '나만의 기록 템플릿 세트'가 완성됩니다. 모두 비식별 사례로.
① 노인 사례기록 — 독거 어르신 1건 사례기록 세트.
힌트: "아래 비식별 메모로 사례기록을 작성해줘. 양식: 기본정보/욕구/강점·자원/위험요인/목표/개입계획. 사실·의견 구분. [메모]"
② 장애인 사례기록 — 자립지원 대상 사례기록.
힌트: "위와 같은 양식으로 지체장애 자립지원 대상자의 사례기록을 작성해줘. [비식별 메모]"
③ 아동·청소년 사례기록 — 지역아동센터 아동 1건.
힌트: "아동 사례기록을 보호자·학교 연계를 포함한 양식으로 작성해줘. [비식별 메모]"
④ 우리 기관 맞춤 템플릿 — 기관 서식 항목으로 템플릿 제작.
힌트: "우리 기관 사례기록 항목은 [항목 나열]이야. 이 항목에 맞춰 메모를 정리해 주는 재사용 프롬프트를 만들어줘."
⑤ 과정기록(모니터링) — 월 점검 과정기록 정리.
힌트: "아래 월 점검 메모를 과정기록으로 정리해줘. 목표 대비 변화·특이사항·다음 계획 포함. [메모]"
2주차

보고서와 사업계획서

사업계획서·결과보고서·회의록의 '논리 뼈대'를 세우고 살을 붙입니다.

오늘의 목표 — 사업계획서 초안을 논리 구조에 맞춰 완성한다.

1. 좋은 기획서의 논리

필요성(문제) → 목적 → 목표(측정가능) → 세부내용·일정 → 예산 → 기대효과 → 평가방법

2. 사업계획서 뼈대

📋 사업계획서 outline
너는 사회복지 프로그램 기획자야. 아래로 사업계획서 초안을 써줘.
- 사업명: 독거 어르신 '마음 돌봄' 말벗 프로그램 / 대상: 20명 / 기간: 6개월
- 구성: 필요성, 목적, 목표(측정가능 3개), 세부 추진내용, 추진일정(표), 예산 항목(예시), 기대효과, 평가방법
- 어조: 공식 문체 / 구체 수치는 [  ]로

3. 결과보고서

📋 결과보고서
아래 운영 내용을 결과보고서로 정리해줘.
- 구성: 개요 / 추진실적(목표 대비) / 주요 성과 / 참여자 반응 / 아쉬운 점 / 개선 방안
- 숫자가 비면 [  ]로
[운영 메모 붙여넣기]
실습

내가 맡은(또는 맡고 싶은) 사업계획서 초안 1건을 완성하세요.

체크포인트

  • 논리 구조로 기획서를 세웠다
  • 결과보고서 틀을 만들었다
🗂 2주차 실습 프로젝트 5 — 보고서·기획서
논리 구조(필요성→목적→목표→내용→예산→기대효과→평가)를 몸에 익히는 연습입니다.
① 신규 프로그램 사업계획서 — 새 프로그램 1건 계획서.
힌트: "'○○ 프로그램' 사업계획서 초안을 써줘. 필요성·목적·측정가능 목표3·세부내용·일정표·예산예시·기대효과·평가방법. 수치는 [ ]로."
② 분기·연간 결과보고서 — 운영 메모로 결과보고서.
힌트: "아래 운영 메모로 결과보고서를 써줘. 개요/목표 대비 실적/성과/참여자 반응/개선방안. [메모]"
③ 사례회의 회의록 — 회의 메모를 공식 회의록으로.
힌트: "아래 사례회의 메모를 회의록으로 정리해줘. 안건/논의/결정/담당·기한. [메모]"
④ 예산 계획 표 — 사업 예산 항목 표 작성.
힌트: "'○○ 프로그램' 예산 계획 표를 만들어줘. 항목·산출근거·금액 열로, 합계 포함(금액은 [ ])."
⑤ 사업 필요성 한 장 — 문제분석 기반 필요성 서술.
힌트: "'○○ 문제'에 대한 사업 필요성을 한 장으로 써줘. 문제 현황·대상의 어려움·개입 근거 포함(통계는 내가 확인한다고 전제)."
3주차

홍보·디자인 자동화

카드뉴스·포스터·소식지·발표자료를 디자인 몰라도 빠르게 만듭니다.

오늘의 목표 — 홍보 카드뉴스와 포스터를 직접 만들어 본다.

1. 홍보 문구부터

📋 카드뉴스 문구
'마음 돌봄 말벗 프로그램' 참여자 모집 카드뉴스 문구를 만들어줘.
- 3컷: (1)공감 메시지 (2)프로그램 소개 (3)참여 안내
- 각 컷: 큰 제목 1줄 + 설명 1~2줄, 따뜻하고 간결하게

2. 디자인 만들기 (따라하기)

· Canva (canva.com)

  1. 가입 → 검색창에 "카드뉴스"/"포스터"
  2. 마음에 드는 템플릿 선택
  3. 글자를 위 문구로 교체, 색·사진 변경
  4. [공유]→[다운로드]

· Gamma (gamma.app) — 발표자료 자동생성

  1. [Create new]→Generate
  2. 주제 한 줄 입력(예: "말벗 프로그램 사업 발표")
  3. 자동 생성된 슬라이드 수정 → PDF/PPT 내보내기

· 미리캔버스 (miricanvas.com)

한국형 템플릿(소식지·현수막·포스터)에 편리. 사용법은 Canva와 비슷합니다.

3. 이미지 생성 (필요할 때)

📋 이미지 생성(ChatGPT/DALL·E)
따뜻한 느낌의 일러스트를 그려줘.
노인과 젊은 봉사자가 손을 맞잡고 웃으며 대화하는 장면,
밝고 부드러운 색감, 특정인처럼 보이지 않게, 텍스트는 넣지 말고.
⚠ 저작권·초상권 — AI 이미지는 도구 약관 확인, 실제 사진·유명 캐릭터·로고 모방 금지. 참여자 사진 사용 시 반드시 동의.
실습

내 프로그램 카드뉴스(3컷) + 포스터 1장을 만들어 저장하세요.

체크포인트

  • 홍보 문구를 만들었다
  • Canva/Gamma/미리캔버스로 결과물을 만들었다
  • 저작권·초상권 주의를 안다
🗂 3주차 실습 프로젝트 5 — 홍보·디자인
문구는 AI로, 디자인은 Canva·Gamma·미리캔버스로. 저작권·초상권에 유의하세요.
① 카드뉴스 3컷 — 프로그램 모집 카드뉴스 문구 + Canva 제작.
힌트: "'○○ 프로그램' 모집 카드뉴스 문구 3컷을 만들어줘. (공감/소개/신청), 각 컷 제목+설명."
② 프로그램 포스터 — 포스터용 헤드라인+서브 문구 → 미리캔버스.
힌트: "포스터용 핵심 문구를 추천해줘. 강한 헤드라인 1 + 서브 1 + 하단 안내 1."
③ 월간 소식지 한 꼭지 — 활동 소식 기사 1편.
힌트: "지난달 '○○ 활동'을 소식지 기사로 써줘. 300자, 따뜻하고 생생하게. [활동 메모]"
④ SNS 게시글 3개 — 인스타용 짧은 게시글 + 해시태그.
힌트: "'○○ 프로그램'을 알리는 인스타 게시글 3가지 버전과 해시태그를 만들어줘. 친근한 톤."
⑤ 발표자료 초안 — Gamma로 사업 발표 슬라이드.
힌트: "'○○ 사업 발표' 슬라이드 개요 8장(제목+핵심)을 만들어줘." → Gamma에 입력
4주차

설문·데이터·녹취 자동화

설문 설계, 엑셀 수식 도움, 회의·인터뷰 녹취록 자동 생성을 익힙니다.

오늘의 목표 — 만족도 설문을 설계·요약하고, 녹취를 회의록으로 만든다.

1. 만족도 설문 설계

📋 설문 문항
'말벗 프로그램' 참여 어르신용 만족도 설문을 만들어줘.
- 5점 척도 8개(만족도·도움정도·재참여의사 등) + 주관식 2개(좋았던 점/개선점)
- 어르신이 이해하기 쉬운 문장 + 설문 안내문(인사말)

2. 설문 결과 요약

📋 결과 요약
아래 설문 결과를 보고서용으로 요약해줘.
- 문항별 평균·주요 경향 / 주관식을 3~4개 주제로 묶기 / 개선 제안 3가지
[집계 결과 붙여넣기]

3. 엑셀 수식 도움받기

📋 엑셀 수식(ChatGPT/Gemini)
엑셀 수식을 알려줘.
- A열: 이름(비식별), B열: 출석 횟수, C열: 만족도 점수
- ①전체 평균 출석 ②만족도 4점 이상 인원 수 ③출석 8회 이상이면 "우수" 표시
각 수식과 넣을 칸도 설명해줘.

4. 녹취록 자동 생성 — Clova Note

  1. 네이버 Clova Note 접속 → [새 노트]
  2. 회의·인터뷰 녹음 또는 파일 업로드
  3. 자동 생성된 텍스트 복사
  4. 그 텍스트를 AI에 넣어 회의록화:
📋 녹취→회의록
아래 녹취록을 공식 회의록으로 정리해줘.
- 안건 / 핵심 논의 / 결정사항 / 담당자·기한
- 사담·반복 제외, 발언 지어내지 말 것
[녹취록 붙여넣기]
⚠ 녹음 동의 — 회의·상담 녹음은 참석자 동의를 받고, 민감정보 녹취는 보안에 유의하세요.
수료 과제

내 사업 1건으로 기획서 + 홍보물 + 결과요약(또는 설문결과) 3종 묶음을 제출하세요.

수료 체크

  • 사례기록·보고서·기획서를 AI로 만든다
  • 홍보물을 직접 제작한다
  • 설문·엑셀·녹취록을 활용한다
🗂 4주차 실습 프로젝트 5 — 설문·데이터·녹취
설계→수합→요약의 흐름을 반복하세요. 녹음은 참석자 동의 후 진행합니다.
① 만족도 설문 설계 — 척도 8 + 주관식 2 설문.
힌트: "'○○ 프로그램' 만족도 설문을 5점 척도 8문항+주관식 2문항으로 만들어줘. 안내문 포함."
② 설문 결과 요약 — 집계 결과를 보고서 문단으로.
힌트: "아래 집계를 요약해줘. 문항별 평균·경향, 주관식 주제 묶기, 개선 제안 3. [집계]"
③ 엑셀 수식 3개 — 출석·점수 계산 수식 받기.
힌트: "엑셀: A열 이름, B열 출석, C열 점수. ①평균 출석 ②4점 이상 인원 ③8회 이상 '우수' 표시 수식과 넣을 칸 알려줘."
④ 간단 욕구조사 설문 — 신규 사업용 욕구조사.
힌트: "○○ 대상의 욕구를 파악하는 간단 설문 10문항을 만들어줘. 결과를 기획에 쓰는 법도 한 줄."
⑤ 회의 녹취 → 회의록 — Clova Note 녹취를 회의록으로.
힌트: "아래 녹취록을 회의록으로 정리해줘. 안건/논의/결정/담당·기한. [녹취록]" (식별정보는 비식별 후)

1비식별 사례 → 사례관리 기록 세트

- 구성: 필요성, 목적, 측정가능 목표 3개, 세부내용, 일정표, 예산 예시, 기대효과, 평가방법
- 수치는 [  ]로

3프로그램 홍보 카드뉴스 + 포스터
