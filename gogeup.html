1주차

나만의 AI 비서 만들기

매번 긴 지시를 반복하지 않도록, 업무별 '전용 도우미'를 만들어 둡니다.

오늘의 목표 — '공문 도우미' 또는 '사례기록 도우미'를 만들고, 프롬프트 라이브러리를 구축한다.

방법 A — 프롬프트 라이브러리 (무료·누구나)

  1. 문서에 업무별 프롬프트를 모읍니다(공문/사례기록/보고서/홍보)
  2. 각 프롬프트에 [여기에 내용] 자리를 비워 둡니다
  3. 필요할 때 복사 → 내용만 채워 붙여넣기

방법 B — Claude Projects (무료 플랜 가능)

  1. claude.ai → Projects → [새 프로젝트]
  2. 프로젝트 지침에 역할·규칙 입력(아래 예시)
  3. 이후 그 프로젝트 대화에 지침이 자동 적용
📋 '사례기록 도우미' 지침 예시
너는 우리 기관의 사례기록 도우미야. 항상 아래 규칙을 지켜:
1. 입력은 '비식별 메모'로 가정하고, 식별정보가 보이면 경고한다.
2. 출력 양식: 기본정보요약 / 욕구 / 강점·자원 / 위험요인 / 목표 / 개입계획
3. 메모에 없는 사실은 지어내지 말고 [확인 필요]로 표시한다.
4. 사실(관찰·진술)과 사회복지사 의견을 구분한다.
5. 객관적·전문적 어조를 유지한다.

방법 C — ChatGPT GPTs (유료일 수 있음)

[GPTs 탐색]→[만들기]에서 위 지침을 넣어 전용 챗봇을 만듭니다. 기능은 Claude Projects와 비슷합니다.

실습

가장 반복되는 업무 1개를 골라 나만의 도우미(프로젝트 또는 프롬프트 세트)를 만드세요.

체크포인트

  • 재사용 가능한 업무 도우미를 1개 만들었다
  • 프롬프트 라이브러리를 시작했다

2주차

공모사업·프로포절 전략

공모 요강을 분석해 '뽑히는 제안서'의 논리와 성과지표를 설계합니다.

오늘의 목표 — 실제 공모 1건의 요강을 분석하고 제안서 초안·논리모델을 만든다.

1. 공모 요강 분석

📋 요강 분석
아래 공모 요강을 분석해줘.
- 이 사업이 '진짜 원하는 것'(심사 포인트)
- 꼭 포함할 항목과 평가 기준
- 강조하면 좋은 차별점 5가지 / 놓치기 쉬운 주의사항
[요강 붙여넣기]

2. 논리모델 + 성과지표

📋 논리모델·지표
'독거 어르신 말벗 프로그램'의 논리모델을 만들어줘.
- 투입(자원)/활동/산출(output)/성과(outcome: 단기·중기)
- 각 성과의 측정 지표와 측정 방법(설문·기록)을 표로
- 산출지표와 성과지표를 구분

3. 제안서 초안

📋 제안서 초안
위 분석·논리모델을 반영해 제안서 초안을 써줘.
- 구성: 필요성/목적·목표/대상/추진전략·내용/추진일정/예산개요/기대성과·평가/사후 지속방안
- 심사 포인트를 앞부분에서 분명히 / 과장 없이, 수치는 [  ]로
⚠ 검증·정직성 — 통계·선행사례·법적 근거는 출처 확인. 실적·수치를 부풀리지 않습니다(사후 평가·감사 대상).
실습

관심 있는 실제 공모 1건으로 요강분석→논리모델→제안서 초안까지 만들어 보세요.

체크포인트

  • 심사 포인트를 뽑았다
  • 논리모델·성과지표를 설계했다
  • 제안서 초안을 작성했다
🗂 2주차 실습 프로젝트 5 — 공모·프로포절
실제 공모 요강 1건을 정해 ①~⑤를 순서대로 적용하면 제안서 한 편이 완성됩니다.
① 요강 분석 — 심사 포인트·필수항목·평가기준 추출.
힌트: "아래 공모 요강을 분석해줘. 심사 포인트, 필수 항목, 평가 기준, 주의사항. [요강]"
② 차별점 5가지 — 우리 기관 강점 기반 차별화 아이디어.
힌트: "이 공모에서 우리가 강조하면 좋은 차별점 5가지를 제안해줘. 우리 강점: [나열]"
③ 논리모델 설계 — 투입-활동-산출-성과 표.
힌트: "'○○ 사업'의 논리모델을 표로. 투입/활동/산출/성과(단기·중기)와 측정지표·방법, 산출·성과 구분."
④ 예산 산출 근거 — 예산 항목별 산출 근거 작성.
힌트: "아래 예산 항목의 산출 근거를 문장으로 써줘(심사자가 납득하게). [항목·금액]"
⑤ 제안서 초안 — 분석·논리모델을 합친 제안서.
힌트: "위 내용을 반영해 제안서 초안을 써줘. 필요성/목적·목표/대상/전략·내용/일정/예산개요/기대성과·평가/사후지속. 과장 없이, 수치는 [ ]."

프로그램 전주기 설계와 평가

욕구조사부터 평가까지, 특히 '성과를 증명하는 평가'를 설계·분석합니다.

📋 욕구조사
지역 독거 어르신의 정서적 욕구를 파악하는 욕구조사를 설계해줘.

2. 설문 결과 분석 (정량)

📋 정량 분석
아래 사전·사후 설문 결과를 분석해줘.
- 문항별 사전/사후 평균 변화와 의미 / 성과를 보여주는 핵심 수치 3 / 보고서용 요약 문단 1
(통계적 유의성은 단정 말고 '경향'으로)
[사전/사후 집계 붙여넣기]

3. 인터뷰·주관식 분석 (정성)

📋 질적 분석(코딩)
아래 비식별 인터뷰 내용의 질적 분석을 도와줘.
- 반복 주제(테마) 3~5개로 묶고 대표 발언 인용
- 효과와 개선점을 주제별로 / 발언 지어내지 말 것
[비식별 인터뷰 붙여넣기]

4. 평가보고서 종합

📋 평가보고서
위 정량·정성 분석을 합쳐 평가보고서를 써줘.

실습

내 프로그램(또는 가상 데이터)으로 평가보고서 1건을 완성하세요.

체크포인트

윤리·보안 심화 + 기관으로 확산

개인정보·윤리 기준을 세우고, 우리 기관 'AI 활용 가이드'를 만들어 동료와 나눕니다.

오늘의 목표 — 기관 AI 사용 가이드라인을 만들고, 동료 교육 자료를 준비한다.

1. 사회복지와 AI 윤리·보안 핵심

  • 개인정보보호법 — 식별정보의 외부(AI) 입력은 유출 위험. 비식별·최소수집.
  • 윤리강령 — 비밀보장, 자기결정, 전문적 책임.
  • 환각·편향 — 오류·편견 가능성, 사람이 검토.
  • 기록·책임 — 최종 산출물의 사실성·적절성 책임은 사회복지사.

2. 기관 AI 사용 가이드라인

📋 기관 가이드 초안
사회복지기관 직원용 'AI 활용 가이드라인' 초안을 만들어줘.

- 개인정보 비식별화 절차(체크리스트) / 산출물 검토·승인 절차
- 1페이지로 읽기 쉽게
💡 팁 — 기관 보안 담당자와 공유해 공식 문서로 발전시키면 기관 전체가 안전하게 씁니다.

3. 동료 교육 자료

📋 동료 교육자료
동료에게 'AI로 업무 효율화하기'를 20분 교육할 자료를 만들어줘.
- 슬라이드 개요 8장(제목+핵심) / 함께 해볼 실습 1개 / 개인정보·검증 주의사항

① 기관 AI 활용 가이드(1p) 또는 ② 나만의 자동화 도구 + 공모 제안서 중 하나를 완성해 발표하세요.

수료 체크

힌트: "직원용 'AI 활용 가이드 1페이지'를 만들어줘. 허용/금지/비식별 체크리스트/검토·승인 절차."

힌트: "AI에 자료를 넣기 전 확인할 개인정보 비식별화 체크리스트를 5줄로 만들어줘."
③ 동료 교육 20분 자료 — 슬라이드 개요 + 실습 1개.
힌트: "동료에게 'AI 업무 활용'을 20분 교육할 슬라이드 개요 8장과 실습 1개를 만들어줘." → Gamma로 제작

힌트: "AI가 만든 문서를 내보내기 전에 확인할 '사실·오류 점검 체크리스트'를 만들어줘(제도·수치·인용 중심)."

반복 연습 예제 5선 — 전문가로 가는 훈련

고급 산출물은 한 번에 완성되지 않습니다. 아래 5개를 실제 업무로 반복하면 'AI를 전략적으로 쓰는 전문가'가 됩니다.

1나만의 '공문 도우미' 만들고 테스트

상황 — 매주 반복되는 공문 작성을 자동화하고 싶다.
만들 것 — Claude Projects(또는 프롬프트 세트) '공문 도우미' + 실제 공문 2건으로 테스트
📋 지침(프로젝트)
너는 우리 기관의 '공문 도우미'야. 규칙:
1. 공문체(간결·정중)로 쓴다.
2. 항상 포함: 제목, 수신, 목적, 주요 내용, 협조/요청 사항, 문의처.
3. 수치·날짜·담당자는 [  ]로 비워 둔다.
4. 민감정보가 입력되면 경고한다.
이제 작성할 공문의 주제를 한 줄로 주면 초안을 만들어줘.
💡 잘 되면 '사례기록 도우미', '보고서 도우미'도 같은 방식으로 늘려 라이브러리를 키우세요.

2실제 공모 요강 분석 → 제안서 초안

상황 — 복지재단 공모(예: 지역사회 통합돌봄)에 지원하려 한다.
만들 것 — 심사 포인트 분석 + 제안서 초안(필요성~사후지속)
📋 힌트 프롬프트
아래 공모 요강을 분석하고 제안서 초안을 써줘.
① 심사 포인트·평가기준·필수항목  ② 우리 차별점 5
③ 제안서 초안(필요성/목적·목표/대상/추진전략·내용/일정/예산개요/기대성과·평가/사후지속)
과장 없이, 수치는 [  ]로.
[요강 붙여넣기]

3논리모델 + 성과지표 설계

상황 — 제안서·평가에 쓸 '성과 증명 틀'이 필요하다.
만들 것 — 투입-활동-산출-성과 논리모델 표 + 측정지표
📋 힌트 프롬프트
'청년 1인가구 고립 예방 프로그램'의 논리모델을 표로 만들어줘.
- 투입/활동/산출(output)/성과(단기·중기)
- 각 성과의 측정지표와 방법(설문·참여율·기록)
- 산출지표와 성과지표를 명확히 구분

4사전/사후 + 인터뷰 → 평가보고서

상황 — 6개월 프로그램이 끝나 성과를 증명하는 평가보고서를 써야 한다.
만들 것 — 정량(사전/사후)·정성(인터뷰) 분석을 합친 평가보고서
📋 힌트 프롬프트
아래 데이터로 평가보고서를 써줘.
- 정량: 사전/사후 척도 평균 변화와 핵심 수치 3
- 정성: 비식별 인터뷰에서 주제 3~5개 + 대표 인용
- 구성: 개요/목표 대비 달성/정량성과/정성성과/한계/개선·제언/종합
- '경향'으로 서술, 발언 지어내지 말 것
[사전·사후 집계]
[비식별 인터뷰]

5우리 기관 'AI 사용 가이드(1페이지)'

상황 — 동료들이 AI를 쓰기 시작했는데 기준이 없어 불안하다.
만들 것 — 허용·금지·비식별 체크리스트·승인절차가 담긴 1페이지 가이드
📋 힌트 프롬프트
우리 기관 직원용 'AI 활용 가이드라인 1페이지'를 만들어줘.
- 허용되는 사용 / 금지되는 사용(식별정보 입력·미검증 배포 등)
- 개인정보 비식별화 체크리스트(5줄)
- 산출물 검토·승인 절차 / 문제 발생 시 대응
- 직원이 벽에 붙여 볼 수 있게 간결하게
💡 완성 후 보안 담당자 검토를 거쳐 기관 공식 문서로 등록하면 가장 좋습니다.
반복 연습법 — 5개를 실제 진행 중인 사업에 적용하며 반복하세요. 1·5번(도우미·가이드)은 한 번 만들면 계속 쓰이는 '자산'이 됩니다.
